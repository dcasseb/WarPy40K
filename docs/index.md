## 🎯 Quick Start

### Install WarPy40K

```bash
# Clone the repository
git clone https://github.com/dcasseb/WarPy40K.git
cd WarPy40K

# Install in development mode
pip install -e .
```

### Run Your First Program

Create a file `hello.wp40k`:
```python
print("For the Emperor!")
print("Welcome to WarPy40K")
```

Run it:
```bash
warpy40k hello.wp40k
```

### Start the REPL

```bash
warpy40k -i
```

## 🌟 Features

- **Warhammer 40K Themed**: Special keywords like `Inquisition`, `Emperor`, `Chaos`, etc.
- **Easy to Learn**: Simple syntax inspired by Python
- **Interactive**: Built-in REPL for experimentation
- **Extensible**: Can be used as a Python library
- **Well Documented**: Complete documentation and examples
